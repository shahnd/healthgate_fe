# HealthGate Frontend

직원 건강관리 시스템 HealthGate의 프론트엔드입니다. React와 Vite를 사용하며, 백엔드 REST API와 연동합니다.

## 기술 스택

- React
- JavaScript
- Vite
- React Router
- Axios
- Tailwind CSS
- Vitest
- ESLint

## 사전 준비

- Node.js
- npm
- 실행 중인 HealthGate 백엔드

## 설치

프로젝트 루트(`healthgate_fe`)에서 실행합니다.

```bash
npm install
