# HealthGate Frontend

직원의 건강과 안전을 한곳에서 관리하는 **HealthGate**의 프론트엔드입니다.  
직원과 관리자가 건강관리 업무를 쉽게 확인하고 처리할 수 있도록 직관적인 웹 화면을 제공합니다.

## 주요 기능

- **직원 관리** — 직원 정보와 조직 정보를 조회하고 관리
- **건강관리** — 건강검진 대상자와 통계, 알림 현황 확인
- **상담 및 예약** — 보건 상담과 예약 일정 관리
- **안전관리** — 안전 브리핑 확인 및 안전문서 관리
- **공지사항 및 병원 관리** — 사내 공지와 병원 정보 관리
- **권한별 화면 제공** — 사용자 역할에 따라 필요한 기능과 화면 제공

## 기술 스택

- React
- JavaScript
- Vite
- React Router
- Axios
- Tailwind CSS

## 프로젝트 구성

HealthGate 백엔드와 연동하는 단일 페이지 애플리케이션(SPA)입니다.  
직원 건강관리 업무를 기능별 화면으로 구성하고, API를 통해 데이터를 주고받습니다.
